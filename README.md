# Democritus – World Chemistry Olympiads Bank

Public site of Democritus, the World Chemistry Olympiads Bank (eisatopon.gr): chemistry olympiad problems — IChO theoretical problems first — in English with LaTeX, statements only.

Live: https://eisatopon.github.io/chemistry-olympiads-bank/

This repository holds only the files the site loads. The problems remain the work of their authors and organising committees.
Sister projects: [World Mathematical Olympiads Bank](https://eisatopon.github.io/national-olympiads-bank/) · [World Physics Olympiads Bank](https://eisatopon.github.io/physics-olympiads-bank/).
